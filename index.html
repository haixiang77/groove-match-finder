RefScope Groove-Match Reference Finder
サーバー

その曲のノリと鳴りに、
限りなく近いリファレンスを。

音声指紋で曲を特定 → Last.fm / iTunes / ジャンル系統樹で候補を収集 → 16ステップのドラム打点・グルーヴ・帯域バランスを波形レベルで照合し、本当に似ている曲だけを残します。

  • 音声のデコードと解析はすべてブラウザ内で実行されます。
  • 外部に送信されるのは、設定したAPI（指紋照合・Gemini）向けの短い抜粋のみです。
  • APIキーなしでも iTunes・MusicBrainz・ジャンル系統樹ベースで動作します。

    使い方と仕組み

    1. 曲をドロップ：ブラウザ内でデコードし、エネルギー最大の30秒（サビ／ドロップ）を自動選択します。
    2. 楽曲同定：AudD / ACRCloud の音声指紋で曲名を特定。失敗時は Gemini の聴取推論 → ファイル名 の順にフォールバックします。曲名は手入力も可能です。
    3. 候補収集：Last.fm の類似曲・類似アーティスト・タグ、MusicBrainz のジャンル、ジャンル系統樹（親・派生・兄弟・影響関係）から iTunes の30秒プレビューを集めます。
    4. 波形フィルタ：全候補のプレビューに入力曲と同じ解析（キック30–140Hz／スネア160–1500Hz／ハイハット6kHz+ の Butterworth 帯域分離 → 16ステップ打点、BPM、キー、スウィング、サイドチェイン、808サステイン、帯域バランス）をかけ、類似度でランク付けします。
    5. 解説：Gemini が数値に基づいて「なぜ似ているのか」を言語化します（キー設定時）。

    APIキー

    すべて任意です。キーがなくても iTunes / MusicBrainz / 系統樹による探索と波形フィルタは動作します。精度を上げたい場合は Last.fm（無料）と AudD または ACRCloud を設定してください。

    CORS プロキシ

    ブラウザから一部のAPIやプレビュー音源にアクセスできない場合は、リポジトリの worker/cors-proxy.js を Cloudflare Workers にデプロイし、そのURLを設定してください。
